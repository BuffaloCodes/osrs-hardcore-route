# CLAUDE.md (global)

Applies in every repo. A repo's own CLAUDE.md adds to this file.
If the two conflict, the repo's file wins for that repo.

@C:/dev/claude-config/anti-style.md

## Who

Pierce is the project manager, not the engineer. Explain commands
and git steps in plain words. Windows machines, repos in C:\dev.

## How to work

- Propose a plan and wait for approval before creating, changing,
  moving, or deleting any file.
- Show each file before saving it.
- One commit per step. Commit only when Pierce says "commit". Push
  only when he says "push". Open a PR only when he says "open a PR".
- Never skip hooks, force-push, or delete data without asking.
- Say plainly when something failed or was skipped. No hedging
  on things that are verified.
- When unsure of a fact, say so and check. Do not guess.

## Names and files

- Lowercase kebab-case for repos, folders, files.
- ISO date prefix (YYYY-MM-DD) on dated files only.
- Uppercase only README.md, CLAUDE.md, PROJECTS.md.
- No spaces, versions, or years in names.

## Never put in a repo

Passwords, API keys, tokens, account numbers, finances, health
logs, a security checklist, family data, or employer-confidential
material. Check before committing.

## Connectors

- Gmail: draft only. Never send.
- Calendar: create events only after approval.
- Never delete mail, accept invites, purchase, or share files.
- Ask permission before any send or edit through a connector.

## Writing

Follow anti-style.md. Pierce reviews everything before it goes out
under his name.
