# OSRS Hardcore Route

A starter guide for Old School RuneScape Hardcore Worlds accounts. It hardens a fresh account so one mistake will not easily kill it, then ends with the Rogue outfit so the account can start a free route or any larger route.

## How to use it

Open `starter-guide.md` and work down the checklist. ⚠ marks a step with death risk. Carry your gp at all times. The guide is written for players with moderate game knowledge, not for new players. Each section ends with a table of estimated levels.
